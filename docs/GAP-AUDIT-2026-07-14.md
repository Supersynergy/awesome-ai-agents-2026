## What is still intentionally not core

- GitStars.io itself is a **measurement/discovery service**, not an agent runtime.
- Synapse is a **local-first memory companion**, not a hosted general-purpose memory backend; its scope is stated explicitly.
- Star velocity never overrides archived status, license, upstream identity, security boundary, or a concrete use case.
- “Claw” projects are listed separately so the family resemblance does not hide material differences in language, isolation, permissions, channels, or maturity.
